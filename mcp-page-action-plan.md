## 1. Hero (первый экран)

**Композиция и выравнивание**
- Title, subtitle и кнопки — **всё прижать влево** (сейчас по центру внутри колонки, выглядит как «две колонки, но всё центрировано»). Кнопки должны начинаться от той же левой линии, что и заголовок.
- Три тега внизу («One MCP / 2,000+ products / SOC 2 Type II») — **оставить по центру**.
- Переключатель Integration / MCP server — Джорджу нравится, **оставляем**, но тоже выровнять по левому краю вместе с остальным.

**Заголовок**
- `SAP EWM` в заголовке сделать **одним цветом** со всем остальным текстом (сейчас выделен синим `s1-h1-accent` — убрать выделение цветом и размером).

**Визуал справа**
- Заменить терминал-мокап на схему-связку: **agent → makini → SAP → другие системы**. makini — центральное звено.
- Вместо «веера» из случайных логотипов баз данных — **квадратная/сеточная компоновка** (веер даёт визуальный диссонанс).
- Логотипы — реальные системы, **квадратного формата из Figma**, нормально подогнанные по размеру (сейчас SAP большой, остальное мелкое).
- **4 статичных логотипа** (узнаваемые, монохромные, со «свечением») + **SAP — цветной и динамический** (подтягивается под страницу).
- Анимация: **точка ездит** между agent → makini → визуалом.

**Защита от дубля логотипа**
- Взять **5 логотипов** и вручную прописать для 4 SAP-страниц исключение, чтобы логотип текущей страницы не дублировался в hero (иначе SAP вылезет дважды).

## 6. How it works / «One managed server…» (#how, схема agent → makini → сервис)

- **Отказаться от компоновки лево/право** — таких блоков на странице уже много.
- Сделать **отдельный блок с центральной композицией: визуал горизонтальный, на всю ширину, крупный**.
- Схема: your agent → makini.mcp → сервис (SAP EWM), **меняется на каждой странице**.

## 7. Capabilities / Benefits (#capabilities)

- Текущий блок — это **Capabilities** (что умеем), а не **Benefits** (преимущества). Это разные вещи.
- Преимущества — **важный, большой блок**, должен быть заметно длиннее обычной секции (как на homepage), потому что здесь по сути раскрывается весь продукт.
- Сетка **по 2 в ряд** (не по 3) → карточки крупнее.
- В **каждой карточке — визуал** (не просто иконка + текст).

## 8. Security (#security)

- По безопасности «there's not much to talk about» — раскрывать сильно не нужно.
- **Поправить перенос в заголовке**: точка в конце строки + перенос выглядят странно.
- **Бейдж/медаль SOC 2** под eyebrow выглядит не на своём месте — **перенести в другое место**.
- Карточки «card-card-card» теряются и читаются как тулзы. Попробовать **другую компоновку** — например, 4 колонки, вертикально. Попросить у AI вариант. **Больше карточек не добавлять** (it's too much).
