# MCP industrial use cases

30 generated industrial photographs in the selected Spectrum treatment. The main Use Case carousel has six original client cases and six fixed photographs. A separate image-only section directly below it displays all 30 images with category tabs.

- `catalog.json`: image IDs, subjects, categories and scene-specific generation prompts.
- `workflows.json`: six original case texts and their image paths, generated by `_build_casestudies.js`.
- `originals/`: 30 ungraded generated JPEG photographs, 1536 × 1024.
- `processed/spectrum/`: selected blue/violet/pink images used by both sections.
- `thumbs/spectrum/`: corresponding 360 × 240 WebP thumbnails for reuse.
- `grade.js`: build-time WebGL fragment shader. Exact core accents: #71a1ff, #9468f2, #ef68f2.
- `review.js`: category tabs for the standalone image library only.

The page displays 1200 × 800 static Spectrum WebP files; it does not run WebGL or image processing on visitors' devices. The carousel and image library are separate sibling sections. Library tabs filter its images only. Images have no click handler, scenario captions or link to the active case. Treatment selectors, localStorage style preferences, Image Direction and Explore all 30 controls are no longer used. Earlier color-treatment experiments are retained locally and are omitted from the developer handoff.

From the repository root:

```powershell
node 'page example/_build_casestudies.js'
node 'page example/_usecase_tools.cjs' bake
node 'page example/_usecase_tools.cjs' verify
node 'page example/_usecase_tools.cjs' serve
```

`bake` and `verify` require Playwright and Chrome for Testing. The tool resolves a project installation or the existing installation under the user's `tools/playwright/`; `PLAYWRIGHT_MODULE` can point to another installation. `serve` uses Node's standard library only and exposes this directory at `http://127.0.0.1:4173/mcp.html#use-cases`. Bake exports Spectrum only and skips existing outputs; use `bake --force` to rebuild them after changing the shader. Verify checks all 30 images, the six-case carousel, independent library tabs and mobile layout.

## Generation prompt

Each image was generated in its own call through `imagegen-mcp`, with `aspect_ratio: 3:2` and JPEG output. The prompt below substitutes the corresponding `scene` from `catalog.json`:

> Use case: photorealistic-natural. Asset type: industrial enterprise website use-case photograph. Primary request: {scene}. Style: premium industrial editorial photography, real full-scale equipment, not a miniature, not a diorama, not a 3D render. Composition: landscape 3:2, strongest subject detail in the upper center and right, clear silhouette and architectural depth, foreground uncluttered. Lighting: cool neutral daylight with realistic practical lighting, rich midtone detail, restrained dark atmosphere, no crushed shadows. Palette: neutral steel gray, desaturated blue, natural material colors; no heavy grading, color will be added afterwards. Constraints: technically plausible equipment and scale; no readable text, no brand marks, no logos, no watermark, no UI, no collage, one coherent scene.

The first inventory-robot image used the same direction with human-eye-height framing and natural brown cardboard. These are generated illustrative scenes, not photographs of Makini customers or their facilities.
