Frequently Asked Questions

Have any questions? We're here to help You

What is the Model Context Protocol (MCP)?

MCP is an open standard for connecting AI agents and LLM applications to external tools and data sources. Instead of building bespoke integrations per system, an agent speaks MCP to a server that exposes tools, resources and prompts. Makini provides a managed MCP server in front of 2,000+ operational systems.

Which MCP clients are supported?

Any MCP-compatible client works, including Claude Desktop, Cursor, ChatGPT and custom agents built with the MCP SDK. You add the Makini endpoint and API key to your client config and the tools appear automatically.

How is authentication and access control handled?

You generate scoped, revocable API keys from the Makini dashboard. Each key can be limited to specific systems, objects and actions, and every call is logged. Makini handles the underlying credentials for each connected system on your behalf.

What data and actions can an agent access?

Agents can read resources (assets, inventory, orders, maintenance history) and call tools to take actions (create work orders, post purchase orders, update stock, trigger workflows). Exactly what is available depends on the connected system and the scopes on the token.

Can I self-host or keep data in my region?

Yes. Makini supports region-specific cloud hosting and self-hosted deployments for customers with data residency or high-availability requirements, so operational data stays within your chosen boundary.

About SAP EWM

SAP Extended Warehouse Management (SAP EWM) is SAP's advanced warehouse management solution for controlling complex warehouse operations at scale — inbound and outbound logistics, storage, stock and labour — deployed on SAP S/4HANA or standalone. Makini's MCP server gives AI agents access to SAP EWM data and workflows without custom development.
