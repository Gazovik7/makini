# Website-ready descriptions (restructured)

## Universal tools

- `get_connection_details`: Return the details of a connection, including which system it points to and the objects and fields available on it. Use it to discover what an agent can do before making other calls.
- `search_raw_data`: Query a system's native entities and fields directly, beyond the unified data model. Reach custom objects and platform-specific data by their original names.
- `get_raw_data_by_id`: Fetch a single native record by its ID in the source system, in the system's own format. Pairs with search_raw_data for custom and platform-specific objects.

## Object tools

- `search_accounts`: Find general ledger accounts by name, number, or type. Returns the chart of accounts and balances.
- `create_account`: Create a new general ledger account. Set its number, name, and type.
- `update_account`: Update an existing account. Change its name, type, or status.
- `search_addresses`: Find addresses by entity or type. Returns billing, shipping, and site addresses linked to records.
- `search_assets`: Find assets by name, type, location, or status. Returns identifiers, location, and maintenance history references.
- `create_asset`: Register a new asset. Set its name, type, location, and tracking identifiers.
- `update_asset`: Update an existing asset. Change its location, status, attributes, or identifiers.
- `search_banks`: Find banks by name or identifier. Returns the financial institutions on file.
- `search_bank_accounts`: Find bank accounts by organization or bank. Returns the account details used for payments.
- `search_boms`: Find bills of materials by product or status. Returns the components, subassemblies, and quantities needed to build a product.
- `search_bins`: Find storage bins by location, zone, or status. Returns bin identifiers and their place in the warehouse layout.
- `search_budgets`: Find budgets by period, unit, or account. Returns planned amounts for comparison against actuals.
- `search_business_units`: Find business units by organization or status. Returns the divisions used to segment operations and reporting.
- `search_contacts`: Find contacts by name, company, or role. Returns individual contact details linked to partners or accounts.
- `search_contracts`: Find contracts by partner, status, or date. Returns terms, value, and renewal details.
- `search_countries`: List countries and their codes used across records.
- `search_credit_notes`: Find credit notes by customer or invoice. Returns credits issued against billed amounts.
- `search_currencies`: List currencies and their codes used in pricing and financials.
- `search_customers`: Find customers by name, status, or identifier. Returns customer profile and account details.
- `create_customer`: Create a new customer record. Set name, contact, and account details.
- `update_customer`: Update an existing customer. Change profile, contact, or account details.
- `search_cycle_counts`: Find cycle counts by status, location, or date. Returns counted quantities versus expected on-hand.
- `create_cycle_count`: Start a new cycle count for a location or bin. Define what to count and the expected quantities.
- `update_cycle_count`: Update an existing cycle count. Record counted quantities or change status.
- `search_employees`: Find employees by name, role, or status. Returns employee records and assignment details.
- `search_fiscal_calendars`: List fiscal calendars defining the accounting year structure.
- `search_fiscal_periods`: List fiscal periods within the accounting calendar.
- `search_fiscal_years`: List fiscal years defined in the system.
- `search_fulfillments`: Find fulfillments by order, status, or date. Returns picked, packed, and shipped quantities against an order.
- `create_fulfillment`: Create a fulfillment against a sales or shipment order. Record what is being picked, packed, or shipped.
- `update_fulfillment`: Update an existing fulfillment. Change quantities, status, or shipment details.
- `search_inventory_adjustments`: Find inventory adjustments by item, location, or reason. Returns the quantity change and reason for each.
- `create_inventory_adjustment`: Adjust on-hand inventory for an item at a location. Record the quantity change and reason.
- `update_inventory_adjustment`: Update an existing inventory adjustment. Correct quantities or reason codes.
- `search_inventory_transfers`: Find inventory transfers by item, source, destination, or status. Returns quantities moving between locations.
- `create_inventory_transfer`: Move inventory between locations or bins. Set the item, quantity, source, and destination.
- `update_inventory_transfer`: Update an existing inventory transfer. Change quantities, locations, or status.
- `search_invoices`: Find invoices by customer, status, or date. Returns billed amounts, lines, and payment status.
- `create_invoice`: Create a customer invoice against a sales order. Set line items, amounts, and terms.
- `update_invoice`: Update an existing invoice. Change lines, amounts, or status.
- `search_items`: Find items by name, SKU, category, or status. Returns item master details including identifiers and units.
- `create_item`: Create a new item in the item master. Set its name, SKU, category, and units.
- `update_item`: Update an existing item. Change its attributes, category, units, or status.
- `search_item_supplies`: Find supply records for items by source or status. Returns expected incoming supply and timing.
- `search_journal_entries`: Find journal entries by account, date, or reference. Returns posted debits and credits.
- `create_journal_entry`: Post a new journal entry. Set the accounts, debits, credits, and reference.
- `update_journal_entry`: Update an existing journal entry. Change lines or reference before posting.
- `search_languages`: List languages configured in the system.
- `search_localities`: List localities such as regions or states used in addresses.
- `search_locations`: Find locations by name, type, or site. Returns warehouses, areas, and storage points in the facility hierarchy.
- `create_location`: Create a new location. Define its name, type, and place in the site hierarchy.
- `update_location`: Update an existing location. Change its name, type, or hierarchy.
- `search_maintenance_templates`: Find maintenance templates by asset type or category. Returns the predefined task sets used to generate recurring maintenance.
- `search_maintenance_triggers`: Find maintenance triggers by asset or condition. Returns the schedules and meter thresholds that launch maintenance.
- `search_meters`: Find meters by asset or type. Returns the measurement points tracked on equipment, such as run hours or cycles.
- `search_meter_readings`: Find meter readings by meter, asset, or date. Returns recorded measurements over time.
- `create_meter_reading`: Record a new meter reading for an asset. Capture the value and timestamp that can trigger maintenance.
- `update_meter_reading`: Update an existing meter reading. Correct the value or timestamp.
- `search_organizations`: Find organizations by name or identifier. Returns the legal or operating entities in the account.
- `search_partners`: Find partner entities by type or status. Returns customers, vendors, and other trading partners in one view.
- `create_partner`: Create a new partner entity. Set its type, name, and contact details.
- `update_partner`: Update an existing partner. Change its type, profile, or contact details.
- `search_payables`: Find payables by vendor, status, or due date. Returns outstanding amounts the organization owes.
- `search_payment_methods`: List available payment methods.
- `search_payment_terms`: List payment terms used on orders and invoices.
- `search_payments`: Find payments by partner, method, or date. Returns incoming and outgoing payment records.
- `search_persons`: Find people by name or identifier. Returns individual person records across the system.
- `search_picks`: Find pick tasks by order, status, bin, or picker. Returns the items and quantities to pick and from where.
- `search_production_operations`: Find operations within production orders by work center or status. Returns step-level progress on the shop floor.
- `search_production_orders`: Find production orders by product, status, or date. Returns quantities, materials, and work center allocation.
- `create_production_order`: Create a production order to manufacture a product. Set the product, quantity, and schedule.
- `update_production_order`: Update an existing production order. Change quantity, status, scheduling, or allocation.
- `search_properties`: Find properties by type or owner. Returns the physical properties and facilities tracked in the system.
- `search_purchase_orders`: Find purchase orders by vendor, status, or date. Returns order lines, quantities, pricing, and delivery terms.
- `create_purchase_order`: Issue a new purchase order to a vendor. Set line items, quantities, pricing, and delivery terms.
- `update_purchase_order`: Update an existing purchase order. Change lines, quantities, status, or terms.
- `search_purchase_requisitions`: Find internal purchase requisitions by status, requester, or item. Returns requested goods and approval status before they become purchase orders.
- `search_putaways`: Find putaway tasks by status, item, or bin. Returns where received goods are being stored.
- `search_quotes`: Find quotes by customer, status, or date. Returns quoted items, pricing, and validity.
- `search_receipts`: Find goods receipts by purchase order, vendor, or date. Returns received quantities and their effect on on-hand inventory.
- `create_receipt`: Record receipt of goods against a purchase order or transfer. Update on-hand inventory and trigger downstream payables.
- `update_receipt`: Update an existing receipt. Adjust received quantities or correct receipt details.
- `search_receivables`: Find receivables by customer, status, or due date. Returns outstanding amounts owed to the organization.
- `create_receivable`: Record a new receivable. Set the customer, amount, and due date.
- `update_receivable`: Update an existing receivable. Change amount, due date, or status.
- `search_rfqs`: Find requests for quotation by vendor, status, or item. Returns pricing requests sent to vendors and their responses.
- `search_return_orders`: Find return orders by customer, vendor, or status. Returns the items being returned and the reason.
- `search_routings`: Find production routings by product or work center. Returns the sequence of operations to manufacture an item.
- `search_sales_opportunities`: Find sales opportunities by stage, owner, or account. Returns deal value, stage, and the associated customer.
- `search_sales_orders`: Find sales orders by customer, status, or date. Returns order lines, quantities, pricing, and fulfillment status.
- `create_sales_order`: Create a new sales order for a customer. Set line items, quantities, pricing, and delivery details.
- `update_sales_order`: Update an existing sales order. Change lines, quantities, status, or fulfillment details.
- `search_shipment_orders`: Find shipment orders by status, destination, or date. Returns the goods in transit and their delivery progress.
- `search_sites`: Find sites by name or region. Returns the physical facilities in the organization.
- `search_spaces`: Find spaces within sites by type or status. Returns rooms, zones, or areas used for operations or maintenance.
- `search_stock_items`: Find stock records by item, location, or bin. Returns on-hand quantity, reservations, and lot or serial details.
- `search_tax_rates`: List tax rates and their codes used on transactions.
- `search_units`: List units of measure used for items and inventory.
- `search_vendors`: Find vendors by name, status, or identifier. Returns supplier profile and terms.
- `create_vendor`: Create a new vendor record. Set name, contact, and payment terms.
- `update_vendor`: Update an existing vendor. Change profile, contact, or terms.
- `search_work_centers`: Find work centers by site or status. Returns capacity, location, and the operations each can perform.
- `search_work_orders`: Find work orders by status, priority, asset, location, or date. Returns assignee, schedule, and the linked asset.
- `create_work_order`: Open a new work order against an asset or location. Set priority, description, due date, and assignee.
- `update_work_order`: Update an existing work order. Change status, priority, assignee, scheduling, or completion details.
- `search_work_requests`: Find work requests by status, requester, asset, or location. Returns the request detail and whether it has become a work order.
- `create_work_request`: Submit a new work request for an asset or location. Capture the issue, requester, and priority before it becomes a work order.
- `update_work_request`: Update an existing work request. Change status, priority, or details.
